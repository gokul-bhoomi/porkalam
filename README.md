# Porkalam (போர்க்களம்)

Porkalam is a free, browser-based fighting game inspired by Tamil and Indian mythology. Play as Mangulan, a mage who can take flight, or Kanalan, an archer who fights at range. Build devotion to call on divine boons that can change the arena mid-fight.

**[Play Porkalam](https://gokul-bhoomi.github.io/porkalam/)**

Play solo against the computer or challenge a friend on the same screen. Use a keyboard or gamepads. Choose **Tutorial** to learn the moves or **Controls** to change your bindings.

## Run locally

With Node.js installed, run:

```sh
npm run serve
```

Open [localhost:5174](http://127.0.0.1:5174/).

Created by [Gokul](https://github.com/gokul-bhoomi). Built with JavaScript and Canvas, with artwork generated using Codex.
