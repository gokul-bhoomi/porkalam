Porkalam art - LIVE BATTLEFIELD (2026-11-21). Owner: the battlefield must be ACTIVE (real fighting behind the
arena, soldiers falling in, arrows, horses and elephants running through), all random so it never repeats.
The game already plays all of this with placeholder code shapes (src/war.js draws, src/sim.js decides); these
images replace the shapes. Owner's art rule: every moving thing is a real frame-by-frame ChatGPT animation
(8-16 frames), never one picture slid or wobbled by code. Code only plays the frames and moves them.

How to run them: ONE NEW ChatGPT chat per image ("Work" mode), paste the prompt as one paragraph (Enter sends),
attach the reference images in [brackets]. ChatGPT saves into /Users/gokul/dev/home/; copy each result into art/
with the given name. Do #1 first; it is the style reference for the rest. Not more than 2 jobs at once.

Shared rules for every sprite sheet (2-15), already written into each prompt:
- painted pixel-art style matching the arena, dark contours, side view from the same high 3/4 camera
- one horizontal strip, frames the same size, evenly spaced, the figure's feet on the same baseline in every frame
- flat pure magenta (#FF00FF) background so the code can cut it out; no shadow on the ground, no text
- the two armies: TIGER army = red cloth, gold trim, round red shields with a gold tiger; FISH army = deep blue
  cloth, pale gold trim, round blue shields with two gold fish. Chola-era South Indian soldiers: bare chest or
  quilted vest, dhoti wrapped for battle, cloth helmet/turban, spear, sword or bow, round shield.
